# 双后端 Embedding 与语义检索练习

> 2026-10-07 产品调整：独立语义检索页面已移除。下文旧页面操作属于历史交付，
> 相应接口保留作开发调试。当前学习入口是
> [内部兴趣匹配、收藏门槛与提醒](discovery-and-library-learning.md)。
> 不再要求用户手动搜资料库；本地模型在发现任务中按需匹配候选。

这轮使用预训练模型，没有训练模型。生成模型（例如 DeepSeek V4-Pro）仍未接入。
Embedding 输出数值向量；检索在 PostgreSQL 中比较向量，而不是要求生成模型“猜出一串数字”。

## 数据流与文件定位

资料版本 → 清洗空白并生成有上限的字符片段 → 选定后端生成文档向量
→ 校验数量/1024 维/有限值并 L2 归一化 → 同一事务保存该版本片段。

用户查询 → 检查后端、当前版本索引和外部发送同意 → 对查询生成向量
→ 同一模型空间精确余弦检索 → 每条资料取最佳片段 → 展示原始来源、范围和相似度。

- `backend/app/retrieval/providers.py`：两个后端、固定模型描述、查询指令、验证与受控错误。
- `backend/app/retrieval/chunks.py`：字符切分基线与截断标记。
- `backend/app/retrieval/service.py`：任务执行、版本选择、部分进度与失败恢复。
- `backend/app/retrieval/api.py`：状态、队列提交、来源过滤和余弦 SQL。
- `frontend/src/SemanticPanel.tsx`：主动操作、同意提示与覆盖展示；并非页面加载就调用模型。
- `backend/tests/test_embedding_providers.py` 和 `test_retrieval_integration.py`：模拟协议与真实隔离 schema 的检索测试。

继续使用一个数据库、已有 Redis 队列和 Worker。两种模型输出同为 1024 维只是简化首版表结构，
不代表语义空间相同。模型、端点、版本标签、指令或切分方式改变，都要建立新的空间。
首版只支持两个固定模型，不是已经兼容所有 Embedding API 或任意维度。

## 任务 1：读懂一条向量和余弦排序

- 输入：已经索引的真实资料，以及查询“向量数据库相似度检索”。
- 输出：页面显示候选、最佳片段、来源范围和小数相似度。
- 补充知识：向量维度、L2 归一化、点积、余弦相似度与距离。
- 验收：解释 PostgreSQL `<=>` 是余弦距离，`1 - distance` 是相似度；0.7 不是“70% 相关概率”。看到相近候选仍需人工检查是否回答你的需求。

## 任务 2：补齐本地索引覆盖

- 输入：页面本地后端的待索引计数；当前交付快照为 18 条待索引。
- 输出：手动每批 3 条执行，直到覆盖全部当前资料。
- 补充知识：队列与任务状态、不可变版本、幂等与 exactly-once 的区别。
- 验收：每批观察 queued/running/succeeded；已完成资料不重复计算。全部覆盖后再建一批不会增加片段。新采集版本需要重新索引，旧向量保留但不能参与当前版本检索。

API 与 Worker 各自首次加载模型，第一次可能较慢；后续复用进程内模型。
单并发 Worker 建索引时采集也会等待，这是个人版控制复杂度的取舍，不是高并发架构。

## 任务 3：对比关键词与语义查询，不夸大结果

- 输入：同一批已索引资料，准备 5 个中英文查询，例如向量检索、网站防护、资料库中实际存在的主题。
- 输出：手动记录各查询前 5 条候选，标注相关/部分相关/无关，并注明检索覆盖。
- 补充知识：关键词漏检、语义误召回、精确最近邻并不保证语义正确。
- 验收：能指出至少一个“字面不同但意思相近”的例子及一个误召回。不在只有 3 条索引时，将结果与全库 21 条关键词查询直接比较并宣称提升。

正式比较需要相同候选集合与人工相关性标签。当前 UI 关键词基线只搜标题，语义索引还读来源片段，
两者既不同算法也不同输入；后续实验应补充同输入基线，拆开解释提升来源。

## 任务 4：安全启用付费后端

- 输入：自己开通的百炼账户，将密钥与控制台 Base URL 存入本地 `.env`，按 README 更新服务。
- 输出：云端显示就绪；勾选外部发送同意后仅索引 1 条，再尝试一个查询。
- 补充知识：认证、地域与业务空间、输入 Token、响应验证、超时并不等于没计费。
- 验收：切到云端时覆盖从该模型自己的索引开始；Network 请求里只有后端选择、材料上限或查询、同意标志，没有 API Key；Key 只由服务器发给受限官方端点。云端失败不自动用本地向量查旧云端索引。

不要将密钥发到聊天。服务标签 `service-v1` 不是公开权重 SHA；云端别名升级时需维护标签并重建。
页面上任务 Token 只是服务商成功返回的索引用量，不含所有查询，也不含超时后的未知费用；最终看服务商账单。

## 当前边界与下一步

长文本最多索引归一化正文前 4100 字符、标题前 200 字符；页面标注截断，完整资料版本未删除。
元数据、摘要/节选、已取得正文区分保留，向量化不能把“只有摘要”变成“读过全文”。
当前没有自动补查、个性化排序、RAG 回答或推荐总结。
下一小块先用人工查询检查召回，再根据失败例子改切分、增加同输入关键词基线；
检索可解释、可评估后再接有引用的回答，而不是立即堆叠更多模型。
